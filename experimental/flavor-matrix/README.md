# Flavor Matrix

A small, structured flavor-pairing database for brainstorming new recipes. Inspired by the foodpairing tradition — Heston Blumenthal's hypothesis, James Briscione's *The Flavor Matrix* (2018), and the underlying volatile-compound science published in food chemistry journals.

This is a **personal-use brainstorming tool**, not a scientific reference. Treat it as a generator of plausible ideas — combinations to try, not facts to cite.

## Layout

```
flavor-matrix/
├── README.md                  ← you are here — schema, conventions, sources
├── USAGE.md                   ← how-to-query guide with worked examples
├── foods.json                 ← source of truth: food → compounds
├── compound_pairings.json     ← source of truth: compound ↔ compound
├── compounds_to_foods.json    ← DERIVED: compound → list of foods (regenerable)
└── generate_index.py          ← script to regenerate compounds_to_foods.json
```

**New here?** Read this file for the structure, then `USAGE.md` for the practical query patterns.

`compounds_to_foods.json` is built from `foods.json` by running the script. Don't hand-edit the derived file; edit `foods.json` and re-run the script.

## How to use it

The matrix supports three reasoning directions:

1. **Food → compounds**: "What does tomato taste like, chemically? What flavor families is it in?" Look up the food in `foods.json`.
2. **Compound → other compounds that pair well**: "If a dish leans on rose/violet (β-ionone, damascenone), what else plays with that family?" Look in `compound_pairings.json`.
3. **Compound → foods that contain it**: "What foods share that violet/raspberry character?" Look in `compounds_to_foods.json`.

The typical brainstorm walks all three:

> Tomato → look up its compounds → β-ionone is one of them → pull β-ionone's pairings (damascenone, linalool, vanillin) → look up which other foods carry those compounds → raspberry, rose, black tea, coriander, basil → propose a tomato-raspberry-basil salad, or a tomato confit with black tea and coriander.

## Schema

### `foods.json`

```json
{
  "tomato": {
    "category": "vegetable",
    "vegetarian": true,
    "vegan": true,
    "compounds": [
      {"name": "Z-3-hexenal", "strength": "high", "notes": "fresh, green, leafy"},
      {"name": "beta-ionone", "strength": "medium", "notes": "violet, floral, raspberry"}
    ],
    "confidence": "high"
  }
}
```

**Fields:**

- `category`: rough bucket — `vegetable`, `fruit`, `herb`, `spice`, `dairy`, `meat`, `fish/seafood`, `legume`, `grain`, `nut/seed`, `fungi`, `fermented`, `sweetener`, `beverage`, `condiment`.
- `vegetarian`, `vegan`: booleans. Eggs/dairy are `vegetarian: true, vegan: false`.
- `compounds`: list of `{name, strength, notes}`. Strength is `high` / `medium` / `low` — how dominant that compound is in the food's flavor profile. Notes are short, plain-English flavor descriptors.
- `confidence`: `high` (well-evidenced in peer-reviewed food chemistry literature), `medium` (common culinary knowledge / FlavorDB-style consensus), `low` (extrapolated or less certain).

### `compound_pairings.json`

```json
{
  "beta-ionone": {
    "pairs_with": ["damascenone", "linalool", "vanillin", "geraniol"],
    "flavor_notes": "violet, raspberry, floral, woody",
    "shared_with_examples": ["raspberry", "violet", "rose", "tomato", "black tea", "carrot"]
  }
}
```

**Fields:**

- `pairs_with`: other compounds that frequently co-occur or are commonly paired in the literature.
- `flavor_notes`: short plain-English description.
- `shared_with_examples`: a few foods that prominently carry this compound (illustrative; the full list is derivable from `compounds_to_foods.json`).

### `compounds_to_foods.json` (derived)

```json
{
  "beta-ionone": [
    {"food": "tomato", "strength": "medium"},
    {"food": "raspberry", "strength": "high"},
    {"food": "carrot", "strength": "medium"}
  ]
}
```

Just an inverted index. Regenerated by `generate_index.py`.

## How to add a new food

1. Add an entry to `foods.json` following the schema.
2. If the food introduces a new compound that isn't in `compound_pairings.json`, add it there too with its pairings.
3. Run `python3 generate_index.py` to refresh `compounds_to_foods.json`.

## Confidence levels — what they mean in practice

- **high** — the compound is consistently identified as a major contributor to that food's flavor in published gas chromatography studies. Trust it.
- **medium** — the compound is widely reported and well-accepted by chefs and food scientists, but the specific intensity for this food may vary by variety / preparation / season.
- **low** — extrapolation from a related food, or culinary tradition without specific compound-level evidence. Use as a starting point, not a citation.

If you build a dish around a pairing and it works, that's the best validation. If it falls flat, the pairing was probably extrapolated; consider downgrading the confidence on the entries involved.

## Scope

Starter set: ~45 foods, ~60 compounds. Skewed toward ingredients Emma actually cooks with, with deliberate inclusion of non-vegetarian items (beef, pork, lamb, anchovy, etc.) so that "what plant food can stand in for this protein?" queries are possible. Extend freely.
