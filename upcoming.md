# Upcoming — things that affect meal planning

A living scratchpad for travel, hosting, busy stretches, or anything else that should shape an upcoming week's meal plan. The weekly Routine reads this alongside `CLAUDE.md` and `preferences.md`.

**How to use:** Add date-stamped entries below. Be brief — a sentence or two is enough. Stale entries (past dates) can be deleted any time; the Routine will quietly ignore them.

**Format suggestion:**
- `**[Month Day, Year]** — what's happening. How it affects meals.`

## Entries

- **June 1–2, 2026 (Mon–Tue)** — On vacation with Alex. No meal planning needed for these days; the week-of-June-1 plan should start Wednesday June 3.
